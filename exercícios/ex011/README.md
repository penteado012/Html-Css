# 🎵 Projeto: Mídias em HTML5

Este projeto demonstra como trabalhar com **mídias no HTML5**, incluindo imagens dinâmicas e reprodução de áudio.  

## 🖼️ Imagem Dinâmica
- Utilização da tag `<picture>` para adaptar imagens conforme a largura da tela.  
- Exibe versões diferentes da imagem em **dispositivos pequenos, médios e grandes**.  

## 🎧 Reprodução de Áudio
- Uso da tag `<audio>` com os formatos **MP3, OGG e WAV**.  
- Recursos adicionados:  
  - `controls` → Controles para o usuário (play, pause, volume).  
  - `autoplay` → Reproduz automaticamente.  
  - `loop` → Repete continuamente.  
- Fallback para download do arquivo caso o navegador não suporte áudio.  

## 📂 Estrutura de Arquivos
- `index.html` → Página principal com imagens dinâmicas e áudio.  
- `imagens/` → Contém versões da imagem em tamanhos diferentes.  
- `midia/` → Contém os arquivos de áudio em vários formatos.  

## 🚀 Objetivo
Praticar o uso de elementos multimídia do HTML5, garantindo responsividade e compatibilidade entre navegadores.  

## 🛠️ Tecnologias
- **HTML5**
