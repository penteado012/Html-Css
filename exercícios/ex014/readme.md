# Projeto: Estilos Locais / Internos em HTML

Este projeto é um exercício prático de HTML que explora a utilização de **estilos locais/internos**, aplicados dentro da tag `<style>` no próprio documento HTML.

## 📌 O que foi praticado

* Definição de **estilos globais** aplicados ao `body` (cor de fundo, família de fontes e tamanho da fonte).
* Personalização de **títulos** (`<h1>` e `<h2>`) com cores e backgrounds.
* Aplicação de **alinhamento justificado** em parágrafos.

## 🖼️ Estrutura do exercício

* **Capítulo 1** com subtópicos 1.1 e 1.2.
* **Capítulo 2** com subtópico 2.1.
* Texto com **parágrafos justificados** e títulos estilizados via CSS interno.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS interno (dentro da tag `<style>`)

## 🔗 Objetivo

Compreender como aplicar **estilos locais** diretamente no HTML, preparando a base para evoluir para **CSS externo** e projetos mais organizados.
