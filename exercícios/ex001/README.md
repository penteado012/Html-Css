Meu Primeiro Exercício HTML
Este projeto é um documento HTML simples, servindo como um primeiro passo no desenvolvimento web. Ele foi criado como um exercício para entender a estrutura básica de uma página HTML.

Conteúdo do Arquivo
index.html: O principal arquivo HTML que contém o conteúdo da página web.

Funcionalidades
Exibe o título "Olá, Mundo!".

Inclui uma linha horizontal (<hr>) para separação visual.

Contém dois parágrafos de texto em português.
