Exercício de Imagens em HTML
Este é um exercício simples para praticar a inserção de imagens em uma página HTML, utilizando diferentes fontes.

Estrutura do Projeto
index.html — O arquivo principal que demonstra como carregar imagens de diferentes locais.

logo-html.png — A imagem do logo HTML (na mesma pasta do index.html).

imagens/logo-css.png — A imagem do logo CSS, localizada em uma subpasta.

Como visualizar
Abra o arquivo index.html no seu navegador de preferência.

Tecnologias
HTML5

O que aprendi
Inserir imagens locais, que estão na mesma pasta.

Inserir imagens que estão em subpastas.

Carregar imagens externas usando uma URL completa.

Utilizar o atributo alt para fornecer uma descrição textual da imagem, importante para acessibilidade.
