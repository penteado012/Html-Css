# 🔗 Projeto: Trabalhando com Links em HTML

Este projeto demonstra como utilizar **links em HTML**, explorando diferentes situações: links externos, internos e opções de download.  

## 🧾 Conteúdo do projeto
- ✅ **Links Externos** – apontando para outros sites e abrindo em nova aba.  
- ✅ **Links Internos** – conectando páginas dentro do próprio site (index, página 2 e página 3).  
- ✅ **Links de Download** – permitindo baixar arquivos em PDF e ZIP.  

## 📂 Estrutura de Arquivos
- `index.html` → Página inicial com links externos, internos e de download.  
- `pag002.html` → Segunda página do site, com link de retorno e referência patrocinada.  
- `noticias/pag003.html` → Terceira página (seção de notícias), com link de volta para a primeira página.  

## 🚀 Objetivo
Exercitar a navegação entre páginas e o uso de links em diferentes contextos.  

## 🛠️ Tecnologias
- **HTML5**
