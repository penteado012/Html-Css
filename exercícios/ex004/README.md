Exercício de Favicon em HTML
Este é um exercício simples para praticar a inclusão de um favicon em uma página web.

Estrutura do Projeto
index.html — O arquivo principal que demonstra como adicionar o ícone na aba do navegador.

cursoemvideo02.ico — O arquivo de ícone (favicon) que aparece no navegador.

Como visualizar
Abra o arquivo index.html no seu navegador de preferência e observe o ícone na aba.

Tecnologias
HTML5

O que aprendi
Adicionar um ícone de favoritos (favicon) à página usando a tag <link>.

Usar o atributo rel="shortcut icon" para definir o tipo de link.

Usar o atributo href para especificar o caminho do arquivo do ícone.

Usar o atributo type para indicar o formato do arquivo (image/x-icon).
