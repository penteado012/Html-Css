# 📋 Projeto: Listas em HTML

Este projeto demonstra como criar e utilizar **listas em HTML**, abordando diferentes tipos e suas variações.  

## 🧾 Conteúdo do projeto
- ✅ **Listas Ordenadas** (`<ol>`) – com diferentes estilos de numeração (1, A, a, I, i).  
- ✅ **Listas Não Ordenadas** (`<ul>`) – utilizando marcadores personalizados (disc, circle, square).  
- ✅ **Listas Aninhadas** – listas dentro de listas para representar hierarquia (ex.: jogos favoritos por console).  
- ✅ **Lista de Definições** (`<dl>`) – estrutura de termos e descrições.  

## 🚀 Objetivo
Exercitar a prática de marcação em HTML, entendendo a aplicação de listas para organização de conteúdo.  

## 🖼️ Estrutura
- **Título principal:** Trabalhando com listas.  
- **Seções:**  
  - Listas ordenadas  
  - Listas não ordenadas  
  - Minhas linguagens favoritas  
  - Meus jogos favoritos  
  - Lista de definições  

## 🛠️ Tecnologias
- **HTML5**
