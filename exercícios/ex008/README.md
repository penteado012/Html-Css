# ✍️ Formatação de Textos em HTML5

Este projeto demonstra o uso das principais **tags de formatação de texto** no **HTML5**, destacando diferenças entre elementos **semânticos** e **não semânticos**.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS (para personalização da tag `<mark>`)

## 📂 Estrutura do código
- **Negrito / Destaque**
  - `<b>` → Negrito (não semântico).
  - `<strong>` → Destaque (semântico).
- **Itálico / Ênfase**
  - `<i>` → Itálico (não semântico).
  - `<em>` → Ênfase (semântico).
- **Texto marcado**
  - `<mark>` → Texto marcado com cor de fundo personalizada via CSS.
- **Texto grande e pequeno**
  - `<big>` → Texto grande (obsoleto no HTML5).
  - `<small>` → Texto pequeno.
- **Texto deletado / inserido**
  - `<del>` → Texto excluído.
  - `<ins>` → Texto inserido (semântico).
  - `<u>` → Sublinhado (não semântico).
- **Texto sobrescrito e subscrito**
  - `<sup>` → Sobrescrito (ex.: x²).
  - `<sub>` → Subscrito (ex.: H₂O).

## 📸 Exemplo de uso
Abra o arquivo `index.html` em qualquer navegador e veja exemplos práticos de como cada formatação é exibida.

## ⚠️ Observação
- Prefira **tags semânticas** (`<strong>`, `<em>`, `<ins>`) sempre que possível, pois ajudam na acessibilidade e SEO.
- Algumas tags como `<big>` e `<u>` são **desencorajadas** no HTML5 e podem ser substituídas por **CSS**.
