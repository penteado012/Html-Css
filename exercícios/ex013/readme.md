# Projeto: Estilos Inline em HTML

Este projeto é um exercício prático de HTML que explora a utilização de **estilos inline** para formatar conteúdo diretamente nas tags.

## 📌 O que foi praticado

* Alteração de **cores** e **tamanhos de fonte** em títulos e parágrafos.
* Aplicação de **background-color** em elementos.
* Definição de **font-family** e **font-size** diretamente no `<body>`.
* Uso do `text-align` para alinhar parágrafos.

## 🖼️ Estrutura do exercício

* **Capítulo 1** com subtópicos 1.1 e 1.2.
* **Capítulo 2** com subtópico 2.1.
* Parágrafos estilizados com **justificação** e títulos personalizados.

## 🚀 Tecnologias utilizadas

* HTML5
* Estilos Inline (atributo `style`)

## 🔗 Objetivo

Fixar o entendimento do uso de **CSS inline** em elementos HTML antes de avançar para folhas de estilo internas e externas.
