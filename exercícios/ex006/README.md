# 📚 Hierarquia de Títulos em HTML

Este projeto é um exemplo prático de como utilizar **títulos hierárquicos (h1 até h4)** em um documento HTML.  
Ele demonstra a estruturação de um texto acadêmico fictício, abordando temas como introdução, metodologia e ordenamento do território em Portugal.

## 🚀 Tecnologias utilizadas
- HTML5

## 📂 Estrutura do código
- `<!DOCTYPE html>` → Define o documento como HTML5.
- `<h1>` até `<h4>` → Usados para organizar os níveis de títulos.
- `<p>` → Parágrafos de texto de exemplo usando *Lorem Ipsum*.
- `<link rel="shortcut icon">` → Adiciona um ícone de atalho (favicon).

## 📸 Exemplo de uso
Abra o arquivo `index.html` no navegador e visualize a hierarquia de títulos.

## ✨ Objetivo
Mostrar a importância de organizar corretamente os títulos para manter a acessibilidade e a semântica de uma página web.
