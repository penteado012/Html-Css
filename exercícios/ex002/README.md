# Exercícios Iniciais em HTML

Dois exercícios simples para praticar a estrutura básica de HTML:
1. `ola-mundo/index.html` — "Olá, Mundo!" com título e parágrafos.
2. `paragrafos/index.html` — exemplos de parágrafos, quebras de linha e entidades HTML.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Tecnologias
- HTML5

## O que aprendi
- Estrutura básica de um documento HTML
- Uso de tags de texto: `<h1>`, `<p>`, `<br>`
- Entidades HTML (ex.: `&copy;`, `&#x1F60E;`)
