# 📝 Outras Formatações em HTML5

Este projeto demonstra o uso de diferentes **tags de formatação no HTML5**, indo além das formatações básicas de texto.

## 🚀 Tecnologias utilizadas
- HTML5

## 📂 Estrutura do código
- **Código-fonte / Pré-formatação**
  - `<code>` → Exibe trechos de código em linha.
  - `<pre><code>` → Mantém a formatação original (quebras de linha e espaços), ideal para exibir código Python, JavaScript etc.
- **Citações**
  - `<q>` → Citação simples, usada dentro de um parágrafo.
  - `<blockquote>` → Citação completa, com opção de usar o atributo `cite` para referência da fonte.
- **Abreviações**
  - `<abbr>` → Mostra o significado completo ao passar o mouse sobre a abreviação.
- **Texto invertido**
  - `<bdo dir="ltr">` ou `<bdo dir="rtl">` → Permite inverter a direção do texto.

## 📸 Exemplo de uso
Abra o arquivo `index.html` em qualquer navegador para visualizar:
- Um exemplo de **código em JavaScript** e **Python**.
- Citações simples e completas.
- Abreviações com tooltip.
- Texto com direção invertida.

## ⚠️ Observação
- Use `<code>` para **trechos pequenos de código** em linha.
- Use `<pre><code>` para **blocos de código**.
- A tag `<bdo>` é pouco usada, mas útil para idiomas que escrevem da direita para a esquerda.
