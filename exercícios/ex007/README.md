# 🌐 Exemplo de Site em HTML4

Este projeto demonstra a criação de uma página simples utilizando **HTML4**.  
Ele foi feito como exercício para comparar práticas antigas de HTML com as recomendações atuais do **HTML5**.

## 🚀 Tecnologias utilizadas
- HTML4

## 📂 Estrutura do código
- `<html>`, `<head>`, `<title>` e `<body>` → Estrutura básica do HTML4.
- `<h1>` → Título principal da página.
- `<p>` → Parágrafo de texto com *Lorem Ipsum*.
- `<u>` → Exemplo de uso da tag de sublinhado (obsoleta no HTML5).
- `style="background-color:"` → Estilo inline aplicado diretamente no `<body>` (também não recomendado nas práticas atuais).

## 📸 Exemplo de uso
Abra o arquivo `index.html` em qualquer navegador para visualizar a página em HTML4.

## ⚠️ Observação
O **HTML4** está obsoleto. Atualmente, recomenda-se o uso do **HTML5**, que oferece melhor semântica, acessibilidade e compatibilidade.
